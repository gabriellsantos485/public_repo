Banner de consentimento gerado para uol.com.br

Gerado a partir do último scan. Para incorporar ao site do cliente, adicione a tag abaixo antes do fechamento de </body>:

<script src="https://cdn.jsdelivr.net/gh/gabriellsantos485/public_repo@main/3/banner.js" defer></script>

Marque cada script de terceiro no HTML do site como . Scripts inline podem usar apenas type="text/plain" data-categoria="..." com o codigo dentro da tag, sem data-src.
